# VibeEmber

VibeEmber is a decentralized, distributed real-time communication platform featuring auto-scaling node clustering and real-time data processing services.

VibeEmber is built to be simple and practical, focusing on doing one thing well.

**Why VibeEmber?**

- VibeEmber is a decentralized, distributed
- real-time communication platform featuring auto-scaling
- node clustering and real-time data

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/VibeEmber.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
